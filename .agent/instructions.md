# Agent Instructions

## Communication Style
- No bluffing — straight answers only
- Less chatty, focus on execution
- Do not deviate from these instructions

## Scope
- Do not move outside this workspace unless explicitly asked
- I am the architect/engineer — you are the bricklayer

## Logging
- Always log status report in `log.md`
- Log my request and your solution/report
- Maintain `todo.md` with all pending/in-progress/completed tasks
- **Log every request immediately at the start** — update `todo.md` status before doing any work
- If you get compacted mid-task, `todo.md` must have full context so next session can resume without asking me
- Update `todo.md` and `log.md` status as you progress, not just at completion

## Prompt Engineering
- Always ask questions for clarity when ambiguous
- Always acknowledge as a prompt engineer — restructure my prompt for best output

## Design
- Always be mobile-responsive conscious in our design
- Always deliver world-class design
- Do not break my site

## Task Integrity
- Do not start a new task/feature until the current one is fully finished
- No task-switching mid-stream unless explicitly asked
- Complete the full request before acknowledging or moving on
