## USAGE NOTES FOR NANOBANANA

- **Aspect ratios:** Use `--ar` parameter as specified per image (e.g., `--ar 4:5` for hero vertical, `--ar 16:9` for landscape, `--ar 1:1` for square, `--ar 3:2` for standard photo)
- **Style:** `--style raw` gives photorealistic results; omit for more artistic interpretation
- **Consistency:** Keep subjects looking Nigerian/Nigerian context for authenticity
- **No text:** Avoid having text in generated images (add via overlay later if needed)
- **Stitching:** Images with `--ar 4:5` or `--ar 1:1` may need border/decorative overlay to match the site's existing grayscale treatment
- **Post-processing:** Apply CSS `filter: grayscale(1)` to maintain current site aesthetic, or use color images for variety
