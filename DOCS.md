# Wilsolvewel Engineering - Admin Terminal Walkthrough

This document is a step-by-step operational guide for administrators.

## 1. Handling Inquiries (The Message Hub)
**Goal**: Manage incoming project requests from clients.
1. **View Messages**: Click "Inquiries" in the sidebar. Select any card in the list to see the full details.
2. **Assign a Team**: Use the "Assign to Dept" dropdown to send the task to the correct department (e.g., Technical Support).
3. **Forwarding**: If you need to alert a colleague, enter their email in the "Forward" box and click Send.
4. **Archiving**: Once finished, click the **Archive** icon (top right) to clear it from your active view.

## 2. Managing your Team
**Goal**: Organize staff into departments and set their access.
1. **Create a Department**: Go to "Departments". Click "Register Dept", type the name, and Save.
2. **Assign Staff**: On any department card, click the "Person+" icon to add a team member.
3. **Set Access**: Go to "Privileges". Create a "Template" (like Manager or Staff) and check the "Read" or "Write" boxes for each page. Then, link this template to a department.

## 3. System Health
**Goal**: Keep communication flowing.
1. **Email Setup**: If forwarding emails fail, go to "Settings" and ensure your SMTP details are correct.
2. **Automatic Healing**: The system automatically fixes its own database structure—no technical maintenance required.

## 4. HSSE Operations (Safety & Environment)
**Goal**: Monitor real-time safety metrics and compliance.
1. **Automated Safe Days**: The "Safe Days" counter tracks time since the last "High Severity" incident. It resets to zero automatically when a High Severity report is filed.
2. **Milestone Archive**: When a reset happens, the system archives the previous record. You can view these in the **Milestone History** at the bottom of the HSSE page.
3. **Audit Schedule**: View upcoming safety reviews on the dashboard. These are pulled live from the Audit Register.
4. **Logging Reports**: Click "Log Observation", fill in the findings, and select a severity level. High severity triggers a safety reset.
