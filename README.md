# Wilsolvewel Engineering Terminal

A high-precision industrial management platform for tracking projects, assets, and logistics.

## Project Brief
Wilsolvewel Engineering Terminal is a centralized hub designed to bridge the gap between industrial field operations and administrative oversight. The platform provides real-time tracking of heavy machinery, project progress reports, procurement logistics, and client support ticketing.

## Key Features
- **Admin Terminal**: Centralized dashboard for managing clients, staff, projects, and system-wide settings.
- **Client Portal**: Dedicated "Terminal" experience for clients to monitor their specific projects, track part deliveries (logistics), and submit technical support tickets.
- **Project Ledger**: Real-time progress reporting with client-staff interaction loops.
- **Asset Register**: Deployment tracking for heavy machinery and equipment.
- **Logistics Command**: Granular tracking of OEM components from procurement to site delivery.
- **HSSE Monitoring**: Health, Safety, Security, and Environmental operation center.
- **Staff ID System**: Virtual ID card generation with PDF export for on-site personnel.

## Technology Stack
- **Backend**: PHP 8.x
- **Database**: MySQL (relational schema for high-precision data)
- **Frontend**: TailwindCSS (Industrial UI/UX), Material Symbols
- **PDF Engine**: html2canvas + jsPDF (client-side generation)
